## Contribution Guidelines
1. **DSA problems**: create `data-structures-algorithms/<topic>/<problem-slug>/` with a `README.md` (statement, approach, complexities) and solutions as `solution.<ext>`.
2. **System design**: fundamentals go in `fundamentals/`, full designs in `case-studies/` using `templates/design-template.md`.
3. **Company pages**: link to the problem folder, never duplicate content.
4. **Diagrams**: store in `resources/assets/` and embed with relative paths.
5. Use `kebab-case` for folder and file names.
